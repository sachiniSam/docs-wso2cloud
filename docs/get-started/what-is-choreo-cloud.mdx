# What is Choreo Cloud?

Enterprises need to build, secure, connect, run, and govern AI agents. Governing an agent requires governing what it touches: the APIs it calls, the integrations it connects through, and the identity it acts under. Choreo Cloud gives you a single platform to govern them all.

## Services

Choreo Cloud has four services: Agent Management, API Management, Integration Management, and Identity and Access Management. Each service manages the full lifecycle of its area, including governance. You access all services through the [Choreo Cloud console](https://console.cloud.choreolabs.com), and they share the same organization, projects, and environments.

### Agent Management

Agent Management is an open control plane for AI agents. Use it to run agents in production and manage their versions and configurations. You can give each agent its own identity, enforce guardrails and governance policies, observe agent behavior, and evaluate it continuously. It also governs agents deployed outside Choreo Cloud, regardless of the framework they're built on.

[Agent Management documentation](https://choreolabs.com/agent-platform/docs/cloud/get-started/what-is-amp/)

### API Management

API Management secures and governs your APIs, AI services, and MCP servers. Use it to proxy REST APIs, route traffic to LLM providers such as OpenAI or Anthropic, and expose your services as MCP tools for AI agents. For LLM traffic, you can apply guardrails and token-based cost controls. It supports each API from design and deployment through to monetization, with developer portals, subscriptions, policies, and analytics.

[API Management documentation](https://choreolabs.com/api-platform/docs/)

### Integration Management

Integration Management runs the integrations you build with Choreo Integrator, such as secure workflows across agents, people, and systems. Use it to push an integration to the cloud, track builds and deployments, and promote it across environments. You can also configure runtime values and security, and monitor logs and metrics, without managing infrastructure.

[Integration Management documentation](https://choreolabs.com/integration-platform/docs/)

### Identity and Access Management

Identity and Access Management verifies, authenticates, and audits the identities of people and AI agents. Use it to add sign-in, multi-factor and passwordless authentication, API authorization, and user management to your applications. It also secures MCP servers and AI agents.

[Identity and Access Management documentation](https://choreolabs.com/identity-platform/docs/)

## One organization across every service

An organization is the top-level tenant boundary in Choreo Cloud, shared by your team. You create one when you sign up, and every service you use belongs to it. Your account is separate: it's you, the person who signs in. See [Organizations](../manage/organizations.mdx).

Choreo Cloud manages these for all services:

- **Users.** You invite users to the organization, and add each one to a [group](../manage/access-control.mdx#groups) that decides what they can do.
- **Projects and environments.** A project or environment you create in one service is available in every service, so one project can hold agents, integrations, and APIs together.
- **Billing.** Billing works the same way for every service, but each service has its own subscription plan and is billed separately. Every organization starts with a 30-day free trial of all services. See [Subscriptions and billing](../manage/subscriptions-and-billing.mdx).

Each service owns the components you build with it, such as agents, integrations, APIs, or identity providers. These components use service-specific names and are documented with their service. See [Key concepts](./key-concepts.mdx).

Each service separates its control plane, where you manage your components, from its data plane, where they run. See [Architecture overview](../architecture/overview.mdx).
